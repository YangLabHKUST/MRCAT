# Skills

Each Skill owns its input contract, scientific requirements and interpretation guide.
Use the public Python functions in `mrcat.tools`; read the selected `SKILL.md` before direct use.

| Skill | Purpose |
| --- | --- |
| [analysis-bidirectional](../skills/analysis-bidirectional/SKILL.md) | Summarize completed forward and reverse MR results for one or more trait pairs; does not fit MR. |
| [analysis-mediation](../skills/analysis-mediation/SKILL.md) | Compute separate two-step mediation estimates from completed X-to-Y, X-to-M and M-to-Y MR results. |
| [analysis-method-comparison](../skills/analysis-method-comparison/SKILL.md) | Compare completed method estimates for one directed pair. Creates figures and numerical summaries; the calling agent interprets the evidence. Does not refit MR. |
| [analysis-replication](../skills/analysis-replication/SKILL.md) | Compare at least two completed study combinations for the same exposure/outcome question; does not rerun studies or pool estimates. |
| [analysis-result-synthesis](../skills/analysis-result-synthesis/SKILL.md) | Summarize completed MR estimates for at least two distinct directed trait pairs; does not fit MR. |
| [analysis-risk-factor-prioritization](../skills/analysis-risk-factor-prioritization/SKILL.md) | Summarize at least two exposures against one outcome from completed MR estimates, with within-method BH adjustment. |
| [analysis-sensitivity](../skills/analysis-sensitivity/SKILL.md) | Run heterogeneity, Egger-intercept, single-SNP, leave-one-out, MR-PRESSO and Steiger diagnostics on a completed primary result record and its exact selected MRdat with at least four instruments. Steiger needs verified trait metadata; filtering/refitting is optional. This is not a generic validator for arbitrary custom MR outputs, single-instrument or correlated-instrument fits, and does not perform colocalization. Plan applicable custom checks when this suite does not fit. |
| [gwas-download](../skills/gwas-download/SKILL.md) | Download one selected remote GWAS study or one user-supplied raw-file URL; preserve metadata and reuse the download cache. |
| [gwas-pair-prepare](../skills/gwas-pair-prepare/SKILL.md) | Joint harmonization, genome-wide LDSC background estimation and LD clumping from two formatted summary-association studies. Always estimates C/Omega with the configured European LD-score reference; use only when both inputs support that background model. Not a standalone harmonization/clumping tool for cis-only, sparse gene-level or preselected-instrument inputs. Those analyses still need compatible pair preparation, implemented with custom code when this combined tool is unsuitable. Internally constructs beta=Z/sqrt(N) and SE=1/sqrt(N) from formatted Z/N; compatible inputs need no separate standardization step. Different required Z/N definitions or transformations need targeted upstream work. Unless the user specifies otherwise, use OpenGWAS API clumping first; after API failure, retry with a verified compatible local PLINK reference and report the reference change. |
| [gwas-qc](../skills/gwas-qc/SKILL.md) | Convert one raw variant-association study into canonical and formatted tables using model-generated mapping and reference-based R formatting. Requires interpretable allele/effect statistics and documented sample-size information for formatting. Canonicalization preserves raw variants; formatted output applies HM3/MHC and allele-frequency filters. Check these filters before using formatted output for a gene-region analysis. Does not select a gene, tissue or cis region, harmonize a pair, or establish MR applicability. Preserves source effect statistics rather than applying the requested MR effect scale. Compatible pair preparation and estimators can standardize from these outputs internally; do not add a separate conversion unless their statistic/sample-size rules or outputs do not meet the request. |
| [gwas-search](../skills/gwas-search/SKILL.md) | Find downloadable GWAS candidates for one trait or source-native identifier. Natural-language UKB or UK Biobank means Pan-UKB; only a complete ukb-* ID identifies OpenGWAS. Preserve supplied phenotype/field IDs unchanged. Search only, without selection or download. |
| [gwas-select](../skills/gwas-select/SKILL.md) | Select one executable study per target from saved shortlists, checking phenotype, source, ancestry and reuse constraints while preserving fixed identifiers. Produces selected study metadata, not an analysis-ready instrument set. Selecting an eQTL study does not establish tissue relevance, cis/trans scope, instrument validity or compatibility with downstream MR methods; those decisions remain part of the analysis. |
| [mr-apss](../skills/mr-apss/SKILL.md) | Fit MR-APSS on LD-clumped MRdat with matching C/Omega estimated from compatible genome-wide studies. This implementation supports only Z/sqrt(N)-standardized inputs. The background model is required, not optional; a sparse single-gene or cis-only association table cannot be assumed suitable. Does not perform cis-region selection, LD-aware cis-MR or colocalization. Preserve an explicitly requested method and assess feasibility rather than substitute another estimator. |
| [mr-bwmr](../skills/mr-bwmr/SKILL.md) | Fit Bayesian weighted MR on harmonized, LD-independent MRdat, with native or Z/sqrt(N)-standardized effects; default minimum is four selected instruments. Models instrument uncertainty and pleiotropic outliers but does not model an instrument LD matrix or perform cis selection or colocalization. Gene-expression data require a compatible instrument set and justified method choice; BWMR is not an automatic follow-up for every MR analysis. |
| [mr-cause](../skills/mr-cause/SKILL.md) | Fit CAUSE causal and sharing models from two genome-wide canonical studies, including its own harmonization and LD clumping. Needs the broad variant universe for nuisance estimation, not cis-only, sparse gene-level or previously selected MR instruments. Consumes neither formatted MRdat nor C/Omega. Does not perform gene/tissue selection or regional colocalization; a custom implementation cannot compensate for missing genome-wide evidence. Internally supports input_scale="standardize" using beta=Z/sqrt(N) and SE=1/sqrt(N) from canonical statistics and documented N; compatible inputs need no separate standardization step. Different required Z/N definitions or transformations need targeted upstream work. Unless the user specifies otherwise, use OpenGWAS API clumping first; after API failure, retry with a verified compatible local PLINK reference and report the reference change. |
| [mr-cml-ma](../skills/mr-cml-ma/SKILL.md) | Fit constrained maximum-likelihood model averaging (cML-MA) on a prepared MRdat table. |
| [mr-conmix](../skills/mr-conmix/SKILL.md) | Fit the contamination-mixture MR estimator and profile confidence intervals on prepared MRdat. |
| [mr-divw](../skills/mr-divw/SKILL.md) | Fit debiased IVW (dIVW) on a prepared MRdat table. |
| [mr-grip](../skills/mr-grip/SKILL.md) | Fit MR-GRIP and its weak-instrument-adjusted estimate on a prepared MRdat table. |
| [mr-lasso](../skills/mr-lasso/SKILL.md) | Fit MR-Lasso with penalized SNP-specific effects on a prepared MRdat table. |
| [mr-mrmix](../skills/mr-mrmix/SKILL.md) | Fit the MRMix mixture model on a prepared MRdat table. |
| [mr-presso](../skills/mr-presso/SKILL.md) | Run MR-PRESSO global, outlier and distortion tests and raw/corrected estimates on prepared MRdat. |
| [mr-primary](../skills/mr-primary/SKILL.md) | Fit the fixed IVW, MR-Egger, weighted-median and weighted-mode suite on harmonized, LD-independent MRdat; default minimum is four selected instruments. Supports native or Z/sqrt(N)-standardized effects. Does not select a cis region, model correlated instruments, perform colocalization, or provide a single-SNP Wald-ratio branch. Use custom estimation when the required estimator or instrument structure is outside this suite. |
| [mr-primary-id](../skills/mr-primary-id/SKILL.md) | Quick fixed IVW, MR-Egger, weighted-median and weighted-mode suite from two OpenGWAS study IDs; retrieves associations, clumps and harmonizes internally. Requires network/authentication; default minimum is four instruments. Supports native or Z/sqrt(N)-standardized effects. Does not consume local files or enforce a gene/tissue/cis-region design, and has no single-SNP Wald-ratio or colocalization branch. An eQTL ID alone does not establish applicability. |
| [mr-raps](../skills/mr-raps/SKILL.md) | Fit robust adjusted profile-score MR (RAPS) on a prepared MRdat table. |
| [mr-robust](../skills/mr-robust/SKILL.md) | Fit robust IVW with robustbase::lmrob on a prepared MRdat table. |

## Adding or changing a Skill

Keep its guide and implementation together under `skills/<skill-id>/`. Update
`mrcat.tools` for the callable interface, the relevant tests, and the Web method
catalogue when appropriate. The registry reads YAML frontmatter; detailed instructions
are loaded only when selected. Planning hints are not executable dependency declarations.

Retain scientific interpretation in the owning Skill. Report generation selects
guidance from the Skills represented in its evidence. Input/output contracts and
numerical checks remain in the tools. A new capability needs evidence and tests
appropriate to its scientific assumptions; a successful process alone is insufficient.
