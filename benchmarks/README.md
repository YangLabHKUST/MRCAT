# Benchmark inputs

`queries.txt` contains 30 research requests. Only the local input directory prefix
has been replaced with `${MRCAT_BENCH_DATA}`; query wording is retained.

Set `MRCAT_BENCH_DATA` to an absolute path and supply the corresponding local files.
See [benchmarking](../docs/benchmarking.md) for dry runs, execution and provenance.
No experimental scores or datasets are bundled.
