# Source-aware replication forest matrix

Rows are MR methods and columns are submitted exposure-outcome study
combinations. When every analysis reuses one study, each column reports the
varying study; otherwise each column reports both exposure and outcome provenance.
The figure omits the overall title and shared-study banner.
Trait and study ID are emphasized, while source, sample size, and ancestry use
smaller regular-weight text. Every available estimate uses the same filled
marker; statistical evidence is read from its confidence interval and reported
P values rather than from a binary fill encoding. Missing cells show incomplete
method coverage. Panels use independent beta axes. Explain the fitted input
representation and any supported unit interpretation in the final report;
a shared input_scale label alone does not establish equal phenotype units
across studies. Different study IDs do not by themselves prove non-overlapping samples.
