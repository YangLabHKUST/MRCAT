# CAUSE ELPD Contribution Diagnostic

This is the third data diagnostic returned by the upstream CAUSE `plot.cause`
method. The x- and y-axes show exposure- and outcome-side effect estimates;
error bars show 1.96 standard errors, point size reflects exposure association
strength, and color reflects each variant's signed contribution to the CAUSE
ELPD model comparison. It is the unmodified package diagnostic and does not add
the publication-specific IVW line or genome-wide-significance triangles.
