# CAUSE Sharing-Model Diagnostic

This is the first data diagnostic returned by the upstream CAUSE `plot.cause`
method. It shows variant-level evidence under the sharing model for exposure
variants with `P < 5e-6`. Use it to identify variants assigned appreciable
probability of acting through the shared factor. Do not infer causality from
this panel alone; interpret it with the causal-model diagnostic and aggregate
ELPD comparison.
