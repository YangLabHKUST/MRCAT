# CAUSE Paper-Style Variant Evidence Plot

This plot follows the display rules described for Figure 4 of the CAUSE paper.
It shows exposure variants at `P < 5e-6`, uses triangles for genome-wide
significant variants at `P < 5e-8`, and draws a dashed IVW slope estimated only
from those genome-wide significant variants. Error bars show 1.96 standard
errors, point size reflects exposure association strength, and the
green-grey-purple scale shows signed variant-level ELPD contribution. The plot
reproduces the publication's visual evidence logic; exact point positions still
depend on the fitted variant set and CAUSE environment.
