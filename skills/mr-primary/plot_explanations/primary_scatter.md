# Primary MR Scatter Plot

This plot shows the selected SNP-exposure and SNP-outcome effects. Horizontal and vertical error bars show one standard error for each SNP effect. Alleles are oriented so that SNP-exposure effects are positive. Each line is one primary MR estimator; the MR-Egger line includes its fitted intercept, whereas the other estimators pass through the origin. Agreement in direction across IVW, MR-Egger, weighted median, and weighted mode is more reassuring than an isolated estimate, but it is not a substitute for formal sensitivity diagnostics.
