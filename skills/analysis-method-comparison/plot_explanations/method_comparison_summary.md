# Effect and instrument summary

Each row combines a method's causal estimate, reported uncertainty interval, exact numeric estimate, and reported instrument count. Most methods have one interval range. A method such as MR-ConMix can have multiple disjoint profile-likelihood ranges; these are drawn as separate segments on the same row and listed with a union symbol in the numeric column. The dashed line marks the null effect (`beta = 0`). Boundary arrows indicate estimates or interval limits outside the displayed forest range.
