# Instrument Beta Scatter

This plot compares `b.exp` and `b.out` for clumped MRdat instruments.

The horizontal position is the SNP-exposure effect, and the vertical position is the SNP-outcome effect. Strong outliers, directional clusters, or sign-discordant points can suggest heterogeneity, pleiotropy, or sensitivity to a small number of instruments.

Use this as a visual diagnostic alongside the method-specific MR result and sensitivity statistics.
