# GWAS Pair Preparation Retention

This plot tracks row counts across formatted exposure, formatted outcome, harmonized Mdat, and clumped MRdat.

It helps show where most variants are lost before MR fitting: exposure/outcome intersection, harmonization, or LD clumping. A very small final MRdat can limit power and may block some MR methods.

Use this as a preparation-stage sanity check before interpreting any MR estimate.
