# Bidirectional mirrored forest

Method names and their colored marker keys occupy the far-left column. The two
central forest panels report forward `X -> Y` estimates first and reverse
`Y -> X` estimates second for the same MR methods. The panels intentionally
use independent effect axes, both labeled `MR estimate (β)`, because reversing trait roles changes units and
instrument selection. All point estimates use filled markers, regardless of
statistical significance. Methods use distinct colors, with the same color on
both sides of each mirrored forest. Horizontal lines show the confidence
intervals in the source results. Pale blue row backgrounds identify the reverse
panel and pale red row backgrounds identify the forward panel. Each forest has
its own P value and IVs columns immediately to its right. The layout is method
keys, forward forest, forward statistics, reverse forest, reverse statistics.
Statistics report the unadjusted p value and instrument count, aligned with the
method's estimates.
Adjusted p values remain in the result table.
Missing cells mean that no compatible method estimate was available in that
direction.
